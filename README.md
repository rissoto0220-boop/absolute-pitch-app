# 絶対音感テスト(本番用)

これは研究用の絶対音感テストアプリの本番プロジェクトです。`absolute-pitch-demo` は画面遷移・操作感を確認するための参照用デモであり、このフォルダーとは別物です(デモは変更しません)。

このプロジェクトの仕様は `absolute-pitch-test/absolute-pitch-test-spec.md` を基準とします。

## 現在の状態(フェーズ2)

参加者ID入力・確認、練習説明、固定3問の練習(円環状回答ボタン・3.5秒の回答時間)、本番開始確認画面まで動作します。本番60問(出題順生成・強制終了・結果表示)、データ保存、CSV出力はまだ実装されていません(フェーズ3以降)。

### 音声について(重要)

`public/sounds/` の3ファイル(D2.wav, F4.wav, Ais6.wav)は、正式なピアノ音源が用意できるまでの**開発用の代替音(サイン波)**です。参照用デモの音源はコピーしていません。研究本番では使用できません。

正式WAVが揃ったら、`public/sounds/` 内の同名ファイルを正式WAVに差し替えてください。差し替え後は `scripts/generate-placeholder-audio.py` は不要になります(削除してかまいません)。

代替音を作り直す場合:

```bash
python3 scripts/generate-placeholder-audio.py
```

## 起動方法

ビルドは不要です。

1. ターミナルでこのフォルダーを開きます。
2. 次のコマンドを実行します。

```bash
python3 -m http.server 8000
```

3. ブラウザで次を開きます。

```text
http://localhost:8000
```

4. 終了するときは、ターミナルで `Ctrl+C` を押します。

## テストの実行方法

追加のパッケージインストールは不要です(Node.js標準のテストランナーを使用します)。

```bash
npm test
```
