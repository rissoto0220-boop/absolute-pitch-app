# 絶対音感テスト(本番用)

これは研究用の絶対音感テストアプリの本番プロジェクトです。`absolute-pitch-demo` は画面遷移・操作感を確認するための参照用デモであり、このフォルダーとは別物です(デモは変更しません)。

このプロジェクトの仕様は `absolute-pitch-test/absolute-pitch-test-spec.md` を基準とします。

## 現在の状態(フェーズ7)

参加者ID入力・確認、練習、本番60問、ブラウザ内保存・中断記録、履歴・CSV出力まで、仕様書のMVP範囲(フェーズ1〜6)を実装済みです。受入条件の確認状況は [PROJECT_STATUS.md](PROJECT_STATUS.md) を参照してください。

### 研究者向けの利用の流れ

1. 正式WAV(60ファイル)を `public/sounds/` に配置する(下記「音声について」を参照)
2. このフォルダーをローカルサーバーで起動する(下記「起動方法」)
3. 参加者に参加者ID(`P00001`形式)を伝え、参加者自身の端末・ブラウザで実施してもらう
4. 実施後、参加者に「履歴・CSVを見る」画面から回答詳細CSV・テスト履歴CSVの両方をダウンロードしてもらう
5. 参加者からCSVを受け取る(受け渡し方法は本アプリの対象外。研究運用に従う)

### 音声について(重要)

`public/sounds/` の60ファイル(C2.wav 〜 H6.wav)は、正式なピアノ音源が用意できるまでの**開発用の代替音(サイン波)**です。参照用デモの音源はコピーしていません。研究本番では使用できません。

正式WAVが揃ったら、`public/sounds/` 内の同名ファイルを正式WAVに差し替えてください。差し替え後は `scripts/generate-placeholder-audio.py` は不要になります(削除してかまいません)。

代替音を作り直す場合:

```bash
python3 scripts/generate-placeholder-audio.py
```

## 起動方法

ビルドは不要です。

1. ターミナルでこのフォルダーを開きます。
2. 次のコマンドを実行します。

```bash
python3 -m http.server 8000
```

3. ブラウザで次を開きます。

```text
http://localhost:8000
```

4. 終了するときは、ターミナルで `Ctrl+C` を押します。

## テストの実行方法

追加のパッケージインストールは不要です(Node.js標準のテストランナーを使用します)。

```bash
npm test
```
